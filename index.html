Generate product data

Enter one Shopify store URL per line. You can paste a homepage or any page from the store.

0 = fetch all public products found. Any positive number acts as an optional cap.
2–3 is polite and reliable. Higher values can trigger rate limits.
Browser-only limitation: a store can block /products.json, require a password, use bot protection, or disallow cross-origin browser requests. This page does not bypass those protections.
